# Atelier AI — A Visual Journey from ChatGPT to Desktop Codex

An interactive, visual, bite-sized learning course (~12 minutes total) designed for someone who has used ChatGPT and wants an intuitive, fun understanding of how AI works — all the way to confidently using a **Desktop Codex** application.

## How to Open

Zero setup or build step required!

- **Easiest way:** Double-click `index.html` to open it straight in Safari, Chrome, or Arc.
- **Or run a quick local server:**
  ```bash
  python3 -m http.server 8000
  ```
  Then open `http://localhost:8000`.

## What's Inside (6 Interactive ~2-Minute Chapters)

1. **Puzzle Pieces & Guesses** — Live Token Splitter + Next-Word Probability Explorer with an interactive **Creativity Dial (Temperature)**.
2. **The Spotlight & Desk** — Interactive SVG **Attention Spotlight** showing how words link meaning across sentences + a visual **Working Desk (Context Window)** that overflows so you can see why starting fresh threads keeps AI sharp.
3. **Improv vs. Open-Book** — Toggle between **Chat-Only (Improv / Hallucinations)** and **Open-Book (Grounded in Real Files)** to see why local tools make AI dramatically more reliable.
4. **Chatbox vs. Agent** — Animated **Read → Plan → Act → Check & Fix** Agent Loop showing how coding agents catch and fix their own mistakes.
5. **Meet Desktop Codex** — Clickable 5-pin guided tour of a Desktop Codex workspace (folders, threads, prompt box, diffs, approve/undo controls) + **Creative Director Prompt Makeovers**.
6. **Your First Codex App (Interactive Sandbox)** — Pick a project folder (*Matcha & Café Journal*, *Weekend Kyoto Planner*, or *Daily Ritual Studio*), direct a simulated Desktop Codex agent in plain English, toggle **Live Preview** vs. **Friendly Diff**, iterate with real upgrades, and unlock a copy-ready **First 5 Minutes Cheat Sheet**.
